## P1：条件恢复使用了数组专有方法

procedures.html 的 setSelectValue（约184行）对 sel.children 直接调用 forEach。真实 DOM 的 children 是 HTMLCollection，不提供该方法。任意非空下拉条件进入此处即异常，loadStatus 的 catch 静默吞掉异常，所以筛选仍为不限且横幅不显示；importFiltersDone 又在成功之前已设为 true。

改为支持原生集合的遍历方式；完整恢复成功后再标记完成。保留缺失选项、当前条件与明确提示，不能遇到异常悄悄放宽条件。

## P1：自动选中事项依赖测试桩的 listeners 属性

procedures.html 的 applyImportProcedureOnce（约227行）调用 c.listeners.click。listeners 是 check-procedures-behavior.cjs 自定义 Element 的测试属性，真实 DOM 没有；代码仍将 found 置 true，因此事项既未选中，也未提示异常。selectedProcedureId 保持 null，doDraft 直接返回。

抽出正常的事项选择函数，由卡片点击和 URL 恢复共同调用，或使用合适的原生 DOM 事件接口。产品代码不得依赖测试桩内部属性。只预选卡片，不自动请求草稿、保存或调用模型。
