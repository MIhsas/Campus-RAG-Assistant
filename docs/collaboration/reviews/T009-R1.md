## R3：题集结构约束缺失（P2）

位置：`evaluation/models.py` 的 Question 和 QuestionDataset。

独立 CLI 均错误返回 exit=0、valid=true：

- 同题重复 evidence_id。
- 改用另一 evidence_id 重复同一 document_id/block_id/start/end。
- is_synthetic="true" 或 1 被普通 bool 自动转换。
- split="test" 被接受，本单只授权 dev。

按原任务补题内 ID 唯一和题内来源区间唯一（两条不同区间仍允许）、严格布尔及 split 固定 dev。不得自动去重或类型转换。重复证据会改变 Recall 分母及权重，即使某次全命中仍是 1 也不能放行。错误应为 DATASET_SCHEMA_ERROR，在解析/检索前停止。

测试分别破坏一个约束：重复 ID 使用不同合法区间；重复区间使用不同 ID；is_synthetic 的字符串 true/false 和数字 0/1 全部拒绝，真实 bool 接受；split test/未知值拒绝，dev 接受。保留合法同块不同区间与跨题复用证据的正例。
