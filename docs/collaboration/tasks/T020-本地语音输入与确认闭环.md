# T020 本地语音输入与确认闭环

日期：2026-09-27；task_revision=v1。Astra 发布，MiMo v2.6 Pro 执行；前置 T019-R1 通过。

## 目标

在现有 ask 页面完成“短录音或上传音频→本地中文转写→编辑确认→用户明确提问”的可见功能。沿用 docs/04 的 ASRAdapter、本地优先、30秒/5MB边界。Windows CPU 可用，不要求 Mac/WSL/CUDA；不接云端 ASR、不调用 DeepSeek、不新增实时通话。

## 实施范围

1. 先核对现有 Python/torch 依赖，选择兼容的 FunASR + Paraformer 离线中文路径作为首选；锁定实际包版本、完整模型标识和模型 revision/哈希。允许安装项目局部可选依赖及下载一份所选公开模型到本项目 .cache，不装系统服务、不全局升级依赖、不修改代理或关闭 TLS 验证。模型安装、首次下载与服务运行分开，服务仅从已配置本地目录加载；未配置明确不可用，不能启动自动下载。
2. 如 FunASR 在当前 Windows/Python 环境有具体兼容阻断，可使用 faster-whisper 多语种 base 的 CPU/int8 作为本任务兼容替代，记录失败原因及替代依据；不同时开发两套实现。不要反复遍历模型。ASRAdapter 保留替换接口，不改变系统整体方案。
3. 新增转写 API 与状态 API（例如 /api/v1/asr/transcribe、/status），响应包含文本、实际 provider/model、音频时长和耗时；无可靠置信度就不伪造。实现真实解码与时长检查，格式至少 WAV 及浏览器实际支持的 WebM/Opus；前端用 MediaRecorder.isTypeSupported 选择支持格式。5MB 和30秒限制在服务端生效；损坏/空音频、未配置、繁忙与执行错误用清晰提示。推理不阻塞事件循环，单并发即可；内存或项目临时文件处理，结束/失败均清理，不保留音频或转写日志。不扩大安全测试矩阵。
4. ask 页面增加录音开始/停止/取消和上传音频入口。只有用户点击才请求麦克风；浏览器拒绝、无设备或非安全上下文时提示并保留上传/文字入口。停止后可明确点击转写；取消与离开释放音轨。录音或转写失败不得覆盖原有问题。识别文本在独立可编辑区域展示，用户点击“使用此文本”才写入问题框；已有文字需明确替换操作。转写完成、使用文本均不得自动 /ask、调用生成器或创建待办；用户仍须点“整理依据/生成答案”。保留既有 query/mode/filters 快照和历史语义。
5. 统一演示脚本支持显式本地 ASR 模型目录参数；问答生成仍为已标记 mock。将本地真实转写与 mock 问答分别标注。mock ASR 如用于测试必须显式注入并标记，不进入正常服务默认路径、不冒充可用模型。
6. 顺手处理 T019-R1 两处说明：未知为用户尚未确认；筛除演示使用下拉可选的2022。不要借此重构规则模块。

## 验证与证据

优先完整交付一次真实本地转写：至少一段来源明确、允许使用的公开或合成中文音频，记录音频来源/哈希、参考文本、原始识别文本、模型标识与耗时；保留实际错字，不能手改成“识别结果”。如使用本地 TTS，标注合成语音，不当作真人准确率。禁止擅自录用户或周围人的声音。可下载公开测试样本，不向第三方上传音频，不调用收费 TTS。

重点测试：转写成功→可编辑文本→确认填入→手动提交；失败保留原问题；取消释放录音；服务端时长/大小与不可解码输入；未配置可继续文字问答。运行相关 pytest、JS语法和 ask 行为回归；依赖有变时 pip check。不跑全部旧功能或 embedding 评测，不把测试数量作为目标。

无浏览器能力须给 Astra 可运行入口与权限拒绝/上传/确认操作表，不能声称麦克风实测。若模型下载或依赖确实受阻，提交已完成代码和准确阻断证据，status=partial、local_asr_verified=false，不用 mock 宣称真实转写完成。模型能够运行则记录 local_asr_verified=true；external_model_calls=0 指无远端推理请求，模型下载单独记录。
