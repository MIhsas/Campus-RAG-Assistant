## 2. 元数据与版本：依据正文，未知如实保留

数据集manifest.jsonl不是现有产品manifest.json，必须显式映射，不直接改后缀或丢弃来源。

- `is_synthetic=false`必须为布尔；source_url选择真实来源记录（附件或来源页），额外来源保留sidecar；source_site与所选URL含义一致。发布主体、转载站点分开记录，学院网站转载不等于院级制度。
- published_at/effective_from/effective_to有正文或来源记录依据才填写；year_hints仅线索，不当日期或入学年份。
- scope的校区/学生类型/年级仅填可支持值，未知按现有契约留空数组。不得将“本科生适用”枚举成所有入学年，不得把文件年份填成admission_year。正文较宽的适用范围而现有结构不能完整表达时，sidecar记录原句与映射限制；未筛选可以检索，用户加条件被保守排除要如实说明，不能关闭筛选规避。
- version_label可据确切文号/正文说明填写，不自封“现行最新版”；policy_group_id仅在确认同一制度版本关系时共享。同标题、不同学院或不同专业不是同一政策组；未核实关系给独立组并记待核实，不凭related_versions自动合并。
- 2023/2026转专业样本首页已看到跨校区规则不同。核对全文的施行/替代条款，保留旧版身份；检索命中某版不等于其适用于当前学生。首批默认生成器关闭。

当前任务不做泛化全文清洗。页眉/换行等沿用既有解析规则；有名单、个人资料或大量无关附录影响首批用途时先暂缓该文档，记录可复核原因。确需派生文本时须另存来源映射和派生hash，不能把改写后的文本冒充原文件字节；优先选无需此类加工的文档完成首批。
