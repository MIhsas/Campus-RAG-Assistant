# T031：指定文件/版本检索与页面闭环

发布日期：2026-10-07；task_revision=v1。安排与验收：Astra；执行：Claude Code中的MiMo。

**目标：** 用户在检索/问答页明确选择一份政策文件后，只从该文件且符合现有适用条件的资料中检索与整理依据，解决指定版本查询混入其他文件的问题。

**架构：** 继续复用 `retrieval/service.py` 的共享检索管线与现有索引；请求增加独立、可选的单文件选择，不改分词/BM25/Dense/RRF/切块算法。来源选择来自用户，不从gold或查询中的模糊年份自动推断。未选择时行为兼容。

**技术栈：** 当前Python/FastAPI、原生HTML/JS、本地BGE；不新增依赖。原协作协议优先于通用技能中的分支/提交建议，无commit/push授权。

## 1. 文件与后端契约

可改：`step2_code/backend/src/campus_assistant/api/search.py`、`api/ask.py`、`retrieval/service.py`，允许新增一个小型来源选择模块；必要响应schema按实际字段同步。不做大规模重构。

- [ ] `SearchRequest` 增加顶层 `document_id: str | None = None`，AskRequest继承。None/未传=全部；空串、非法类型及非当前成功解析文档的ID返回明确422，不能悄悄改成全部。只支持单文件，无多选/搜索词自动猜ID。
- [ ] 新增 `GET /api/v1/search/documents` 返回当前成功解析文档的选择目录：document_id、title、version_label、policy_group_id、published_at、effective_from/to、is_synthetic。未知字段保持null，不猜文号/日期，不暴露磁盘路径、全文或密钥。排序稳定；未配置时返回清晰不可用状态，目录可为空。
- [ ] source selection 与原四项适用条件求交，**交集先准入后TopK**；BM25全库IDF保持，Dense/Hybrid使用同一交集。选择的文件被原筛选排除时返回无准入依据，不取消筛选、不回退其他文件。
- [ ] `search` / `ask` 使用同一实现；来源ID由服务验证与响应回显，展示名称从服务端目录映射。增加独立 `source_selection` 摘要（id/title/version、选择前/最终可准入数量或同等清楚字段），旧 `filter_summary` 若继续保持四条件口径要明确与最终交集的区别，不能计数互相冒充。
- [ ] 选文件不重建索引、不重新编码文档；原文span/preview链接仍由服务器命中映射。generated路径自然使用所选证据，但本任务仅mock验证，不调用真实供应商。
- [ ] 没有document_id的历史调用（Agent/办事/旧评测）不受影响；本任务不为Agent添加模型可写来源参数，也不将来源选择变成资格结论或政策现行判定。
