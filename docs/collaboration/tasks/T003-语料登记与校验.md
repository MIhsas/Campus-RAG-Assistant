## 目标与范围

前台将来从这些字段展示来源链接、政策版本、适用对象；本阶段不开发前端。学校固定背景为四川农业大学，但合成测试资料不得冒充学校公开政策。

## 数据契约

以 UTF-8 JSON 为输入，顶层固定 `schema_version: "1.0"` 和 `documents: [...]`。documents 至少一项；未知字段应拒绝，避免拼写错误被静默忽略。

每项必需字段：

| 字段 | 类型及规则 |
|---|---|
| document_id | 非空字符串，匹配 `[A-Za-z0-9][A-Za-z0-9_-]{0,63}`；一个逻辑文件版本的稳定登记 ID，全清单唯一，不按标题自动猜测 |
| policy_group_id | 同样的 ID 规则，用于人工关联同一政策的不同版本；可重复，不自动认定替代关系 |
| title | 去除首尾空白后非空 |
| source_url | 绝对 http/https URL，必须有主机且不得含用户名/密码；本单不联网验证权威性或可达性 |
| source_site | 非空来源网站名称 |
| local_path | 相对 corpus-root 的文件路径；详见路径约束 |
| sha256 | 64 位十六进制字符串，可归一化为小写，必须与实际文件内容相符 |
| version_label | 非空、人工填写；允许“未标注版本”，不推断发布时间 |
| published_at | YYYY-MM-DD 或 null，未知填 null |
| effective_from | YYYY-MM-DD 或 null |
| effective_to | YYYY-MM-DD 或 null；起止均有值时结束不得早于开始 |
| scope | 对象，含 campus、student_type、admission_years 三个必需数组，未知字段拒绝 |
| is_synthetic | 严格布尔值，禁止字符串 "false" 被隐式转换 |

scope.campus 和 scope.student_type 是去重的非空字符串数组；空数组表示尚未标注，**不能解释为适用于所有人**。admission_years 是去重的四位整数数组（1900—2100）；空数组语义相同。这里暂不固化校区和培养类型字典，以免未核对真实资料就写死业务值。日期必须严格匹配上述日期格式，不接受时间戳或带时间字符串。

不自动去重不同版本，不自动宣布当前有效，也不要求不同登记项文件哈希必须不同；ID 重复必须报错。不要增加数据库、用户鉴权或版本管理服务。

## 离线命令

提供可运行入口，例如：

```powershell
& .\.venv\Scripts\python.exe -m campus_assistant.corpus.validate --manifest .\examples\synthetic-corpus\manifest.json --corpus-root .\examples\synthetic-corpus
```

模块可按 `corpus/models.py`、`corpus/validate.py` 划分，避免过度分层。命令 stdout 输出一个合法 JSON 对象：`valid`（布尔）、`document_count`（已通过结构验证的输入条目数；结构失败时为 0）、`errors`（数组）。成功退出码 0；输入、结构、文件或完整性校验失败退出码 1；命令参数用法错误可沿用 argparse 的退出码 2。成功 errors 为空；失败每项错误至少包含 `code`、`document_id`（无法定位时为 null）、`field` 和中文 `message`。

稳定错误码至少包括 MANIFEST_READ_ERROR、MANIFEST_SCHEMA_ERROR、DUPLICATE_DOCUMENT_ID、UNSAFE_LOCAL_PATH、FILE_NOT_FOUND、FILE_READ_ERROR、HASH_MISMATCH。结构验证失败可返回一个或多个 MANIFEST_SCHEMA_ERROR；结构成功后，应收集各登记项可继续检查的错误，避免一个坏文件掩盖其余问题。不要向 stdout 输出进度、堆栈或机器绝对路径。输入清单不得被命令修改；不生成索引或后台持久化记录。

路径约束：local_path 只允许相对路径，兼容普通中文文件名；拒绝绝对路径、盘符、UNC、`.`/`..` 路径段及 Windows ADS 冒号形式。解析根目录和目标真实路径后再次确认目标位于 corpus-root 内，阻止链接绕出根目录；只有普通文件可校验。检查顺序必须保证不在验证边界前读取目标内容。不存在的文件与不安全路径分别报错。没有创建链接权限时，实测链接逃逸项可标记跳过并说明，不能声称已覆盖。

以分块方式计算 SHA-256，不把整份文件一次性加载内存。此阶段文件不限制 PDF/DOCX 扩展名，因为不解析正文，示例使用小型 txt 即可。
