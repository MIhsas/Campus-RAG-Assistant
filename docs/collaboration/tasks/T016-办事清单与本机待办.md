# T016 办事清单与本机待办

日期：2026-09-27；task_revision=v1。Astra 发布，MiMo v2.6 Pro 执行。前置：T015-R1 验收通过。

## 目标和边界

交付一个完整可演示流程：选择事项与适用范围 → 查看有来源的办理步骤草稿 → 明确保存到本机待办 → 勾选进度、添加个人备注与提醒日期 → 重新打开并继续办理。

本轮是合成资料上的功能原型，不是四川农业大学现行办事指南。沿用 FastAPI 和静态页面，数据模板独立于页面，待办仅存本机 localStorage；不引入数据库、账户、TinyAgent、语音或新的模型调用。正式 Vue/小程序及跨设备同步不在本轮范围。个人待办不上传学校、不提交申请、不代表学校受理。

## 文件与实现步骤

路径均相对于 step2_code/backend；可按已有代码风格微调文件命名并在报告说明。

- [ ] 新建 `examples/procedures/procedures.json`：两个明确标记 is_synthetic=true 的事项模板——缓考申请、成绩复核。各含 procedure_id、标题、模板版本、步骤及精确引用（document_id、block_id、字符范围、原文、sha256）。只从当前 parse-corpus 的实际文本整理，不编造材料、部门、网址或截止日期。对于原文没有说明的项目，显示“资料未说明，请向办理部门核实”，不生成具体要求。
- [ ] 新建 `src/campus_assistant/procedures/service.py` 及 `api/procedures.py`，在 main.py 注册路由。目录与模板位置由应用配置/工厂注入，沿用项目现有方式；测试与演示显式启用合成模板，不将合成指南混入未来真实语料运行。提供 GET `/api/v1/procedures` 和 POST `/api/v1/procedures/{procedure_id}/draft`。draft 输入为与搜索一致的 filters；输出包含模板版本、规范化 filters、步骤、引用及可生成状态。复用既有筛选准入逻辑，逐条核查绑定文档、内容哈希、原文块与引用跨度。无需检索排名或 LLM 抽取：这是来源可核对的固定工作流。
- [ ] 不符合筛选的来源不能进入草稿；必要步骤来源不满足条件、缺失或哈希改变时，返回明确的“资料不足/依据需更新”，不输出一个冒充完整的可保存清单。不自行放宽筛选。两个事项在合适范围下均须可演示；2023 年级不得混入仅适用于 2024 的 DOCX 要求。当前学校资料尚未给出，不从网上临时补政策。
- [ ] 新建 `static/procedures.html`，提供事项卡片、四项筛选、草稿步骤、来源展开/原文跳转和“保存到我的待办”。明确显示合成演示标记、适用范围与未说明项；未点击保存前不写 localStorage。草稿清单不是资格自查，不输出“你有资格/学校已批准”。在 ask/search/preview 导航增加办事入口；不做新的自然语言自动路由。
- [ ] 同页或独立 `static/tasks.html` 实现“我的待办”：保存完整来源快照与模板版本、创建时间、条件、步骤勾选状态；支持刷新恢复、进度（已完成/总数）、个人备注、个人新增步骤、个人提醒日期、删除及未完成/已完成筛选。个人步骤与政策步骤明确区分，不能修改原文后仍标成政策依据。相同保存动作防重复提交；允许用户明确新建另一份清单。存储不可用时不显示“保存成功”，草稿仍可查看；最多保留 20 份，达到上限提示先删除，不静默丢弃旧清单。
- [ ] 提醒日期由用户选定并标注“个人提醒”，按日期升序排列，无日期置后；依据浏览器本地日期区分已过期/今日/以后，不启用通知权限、后台推送或联网。政策里的“考试前”等相对期限保留原文，不在缺考试日期或校历时编造绝对截止日。
- [ ] 历史待办标注“保存时的依据，可能已更新”；提供显式“核对当前依据”操作，调用本地 API 比对来源哈希/模板版本及适用条件。变化或不可用则提示需复核，不静默覆盖勾选/备注，不把旧快照当现行建议。可查看新的草稿并明确另存新清单；本轮不开发通用政策同步系统。
- [ ] 一并完成 T015-R1 三项小整理：pageshow 时同步历史开关与提示；模拟不足演示问题改为有检索命中的“缓考申请模拟不足”并验证；生成结果复制按钮改为“复制回答与来源”，摘录状态使用对应文案。
- [ ] README 写明 Windows 本地启动方式、合成资料边界、本机存储与清理方法；提供可由 Astra 重放的演示步骤。

## 验收重点与验证

只围绕主流程做聚焦验证，不追求测试数量，不扩大安全/边界矩阵：

1. 两个事项均能从当前原文建立有效引用；选不同年级时不会混入不准入的来源。
2. 来源哈希改变或缺失时明确不可用，旧待办核对后标为需复核且保留用户进度。这一项用隔离夹具验证，禁止改产品语料或旧 gold。
3. 保存前零持久化，保存后刷新可恢复；勾选、备注、个人步骤、日期排序、删除可用；个人内容与政策依据区分清楚。
4. 与已有问答/检索共存，T015 三项整理不破坏原快照/历史行为。

运行新增模块相关 pytest、页面 JS 语法和相关行为验证；main.py 仅注册路由时运行相关路由/工厂回归即可，不重复模型下载/编码或全量评测。只有实际发现共享代码回归风险才扩大测试。

有浏览器工具则完成一次完整操作；无浏览器工具则如实说明，交付本地演示入口及步骤给 Astra。模拟与真实证据区分，不伪称学校指南准确率。不调用任何外部模型，不初始化 Git、不安装 WSL、不改系统代理。
