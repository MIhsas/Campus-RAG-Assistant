# T027 v1：检索对照评测与论文证据包

日期：2026-09-28。执行 MiMo；验收 Astra。当前仅本任务授权，零外部模型调用。

## 目标

从功能堆叠转入毕业设计实验：在保留旧8题基线的前提下，建立更有区分度、可人工复查的合成检索评测，实际比较 BM25/Dense/Hybrid，输出可复用的逐题结果与实验报告。真实学校语料未提供，本轮不是校园准确率结论，不需要联网搜集或爬取资料。

## 1. 数据与标注

在独立 examples/evaluation-v2/ 下建立20—30题（数量只作规模建议，不为凑数重复改写）；优先复用已有 parse/PDF/比较合成夹具，可在独立评测目录增加少量明显标注的干扰资料。绝不改旧 examples/evaluation/questions.json、原语料、模板或历史 gold。

覆盖直述、同义改写、少关键词、多个必要依据、相似主题干扰、年份/日期筛选，以及少量材料不足题。至少一组相同问题不同筛选应有不同准入证据。标注每题类型、适用条件、answerable、精确文档/块/跨度、原文引句与判定理由；材料不足题解释缺什么，不把无关命中当答案。

gold 必须依据原文和题目独立制定，不从某种检索模式结果反推。首次正式评测前保存数据/标注哈希；运行后发现真实标注错误可修订并记录前后及原因，不因模型得分低改标准。合成题由模型辅助编写须如实标注，不写成教师/学生独立标注。给出人工复核清单，Astra可抽查。

## 2. 评测管线

扩展或复用现有 evaluation 模块，调用产品同一检索服务和筛选规则，三模式使用相同语料/题集/条件/top_k。复用本地已有BGE模型，禁止下载；缺模型明确报告，BM25部分可先完成，不能悄悄用假向量。

固定 K=5，复用原 Evidence Recall@K/Hit@K/MRR@K 的口径；若增加K=3只作为补充，避免参数搜索。回答可得题与不足题分开分母；不足题报告返回空结果比例和有结果数量，明确“有命中不等于有依据、空检索不等于模型可靠拒答”，不得算入 recall 分母稀释结果。多证据题按既有完整跨度覆盖语义，文档/块身份一致后才计覆盖。

逐题JSON/CSV记录实际排序、分数、证据覆盖、条件、指标；聚合结果含题数/分母，按题型及筛选分组。记录模型ID、语料和题集hash、chunk/top_k/RRF参数、运行命令与版本。若记录耗时，明确索引加载与查询计时边界，不宣称统计稳定性能；不为测速度反复大规模运行。

## 3. 可审阅报告

输出 Markdown 对照表（或由JSON生成的离线HTML报告，任选更简单可复查方式），呈现三模式指标、逐题差异及3—5个有代表性案例（成功/失败/相同结果都可如实展示），引句与来源可回溯。无差异就如实说明样本规模和难度限制，不制造 Hybrid 必须领先的结论。

另写论文实验方法草稿：实验环境、数据来源为合成、标注规则、指标定义、变量控制、主要发现及局限。将 T014真实问答、T025真实规划、当前离线检索的证据分开；不能把 mock结果或旧真实token记录当本轮生成质量实验。列明真实学校资料到位后的替换/补测步骤，不写虚构结论。

## 验证与范围

只需指标小样例手算对照（多证据与不足题各一个）+ 新题集校验 + 三模式一次正式运行。测试聚焦评测适配，不重跑无关前端/ASR/agent/全量；不改产品算法为成绩调参。允许修改 evaluation、新评测脚本、对应测试、独立新夹具与README、submissions/T027。若旧8题兼容接口被改，补一次旧集兼容检查，不篡改旧结果记录。
