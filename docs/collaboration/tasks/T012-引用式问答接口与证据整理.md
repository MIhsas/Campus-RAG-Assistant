# T012 引用式问答接口与证据整理

日期：2026-09-22。发布 Astra。执行 MiMo v2.6 Pro。task_revision=v1，前置 T011-R2 通过。

## 目标

从“搜索结果列表”推进到“围绕问题整理原文证据、逐条打开出处”的页面，并建立可接生成模型的单轮问答接口。运行时模型 API/预算尚未确认，本任务默认只整理原文，不自动生成政策结论。离线协议验证完成后，下一任务再接实际供应商；不要用 fake provider 冒充真实模型。

允许修改 step2_code/backend/、step2_code/README.md、docs/collaboration/submissions/T012/。不改 Astra 文档、既有 gold、历史提交。不安装新框架/全局工具，不调用外部模型或取用 Claude Code 凭据，不接数据库、语音、Agent、多轮会话。复用现有 .venv 和本地模型；默认 BM25，用户明确选择 dense/hybrid 时沿用现有不可用处理。

## 1. 统一检索与证据包

将问答和 /search 共用的三模式检索、筛选、结果映射整理成小型服务函数，避免路由间 HTTP 自调用或复制两套筛选逻辑。不重新解析/分块/编码正文，不改变原搜索响应和排名。保持所有 T011 条件及 None/空集语义。

在一次请求内为 Top-K 命中分配 E1、E2 等 evidence_id。证据包含原文 text、document_id、block_id、chunk_id、char_start/end、document_sha256、标题、来源链接、版本、适用范围、日期、is_synthetic 和 preview_url。ID 只在该请求内有效，不能跨请求用于不相关材料。

证据按实际 chunk 精确摘录、去除重复 chunk，保留半开区间与原文一致；不得无提示改写或拼接成一个假原文区间。上下文预算先用明确的字符上限（建议总计 6000 字符、最多 5 条）；整条装入或整条略过，记录略过数，不称字符预算为 token 预算。不允许 budget 截断后引用仍声称支持未发送的全文。显示 budget_empty 与检索无命中区别，不为超长条目编造摘要。

## 2. API 与模式契约

新增 POST /api/v1/ask：query、mode、filters 与搜索规则一致；answer_mode=extractive|generated，默认 extractive。新增 GET /api/v1/ask/status 表明运行模式、是否配置生成器；不要把系统 health/ready 擅自改为全面就绪。

extractive：返回 status=evidence_only、answer=null、evidence 列表和中文说明“以下是相关原文摘录，尚未生成答案，需核对适用条件”。无检索命中/无符合条件的文档分别说明，不能凭空回答；得分>0 不等于有答案。检索错误依旧是错误，不包装成正常无答案。

generated：本单仅定义可注入的 AnswerProvider 协议，输入为 query、实际选取的证据、筛选条件，输出为结构化段落（text + evidence_ids）或 insufficient_evidence。未配置时明确 503/GENERATOR_NOT_CONFIGURED，不静默把摘录伪装成生成答案。协议可由测试中的 fake 实现，不提供默认假模型端点。不开发未经选择的远程 HTTP 适配器。

对生成器返回值做必要检查：每个事实段落至少有引用；引用 ID 必须属于本次实际输入的证据；空输出/非法格式/未知引用视为生成失败，不把部分坏答案输出给用户。有效引用只证明定位有效，不证明语义支持正确；文档明确仍需真实模型人工评价。provider 的 insufficient_evidence 对应独立状态，不能根据检索非空强行回答。provider 异常不得影响现有搜索/预览；返回可理解错误，可由用户明确切换原文摘录。

保留结构化正文与引用的对应关系，不依靠从任意 Markdown 链接中猜引用。不让 provider 生成文件路径/来源链接，来源由服务从证据映射取得。给未来真实 provider 写简洁提示词模板：只据输入原文、保留条件/数字、材料不足说明不足；不把文档内容当指令。

## 3. 用户页面

新增 /ask 简单单轮页面，与 /search、/preview 互通。复用现有样式和筛选体验，不迁移 Vue，不重复设计整站。

用户输入问题、选条件后点击“整理依据”；显示提交时的问题/条件、醒目的“原文摘录 / 未生成答案”标签、编号证据卡与原文跳转。可复制本次问题、条件和带来源的摘录为纯文本，复制失败给明确提示。不得把相似度显示为答案可信度。

未配置生成器时显示“自动作答未配置”，生成操作禁用但原文整理可用；不要提供 fake 模型开关。为将来 generated 段落+引用预留渲染，测试可用受控响应，不把该测试声称为真实 LLM 演示。

继承请求快照和失败重试规则，异步状态刷新不得清空筛选。合成标记醒目；无证据、条件无匹配、预算装不下和模型未配置状态可理解。原文跳转使用服务端映射。
