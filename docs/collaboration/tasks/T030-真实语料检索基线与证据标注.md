## 1. 原文优先的24题开发集

- [ ] 新建 `questions.json`，`dataset_id=sicau-pilot-eval-v1`、`dataset_version=1.0`、`split=dev`、`schema_version=1.0`、`metric_semantics=fact_group_or_v1.1`。使用现有QuestionDataset契约。
- [ ] 共24题：20题在各自准入集合内有完整依据，4题在该集合内不足。覆盖至少4个业务主题、8份不同原文；直述数字/部门/时限、口语改写、多事实、指定版本差异均应出现。多事实题至少3题，每题2—3个明确必要事实即可。
- [ ] 包含至少2组版本对照问题。问题正文明确政策系列与文号/年份，不只在rationale暗藏版本约束。不得把“最近/当前”默认解释成某个文件或“旧版失效”。
- [ ] 包含至少2组同题不同筛选的对照，直接复用四项conditions。可用日期准入与未知范围排除：每个案例先按实际元数据确认。20份文档的campus/admission_years均为空，不能伪造可答年级条件；模型无法表达的区间如实记录。
- [ ] 4个不足案例区分原因：建议2个“首批资料未记载所问事实”、2个“有相关原文但被本次条件排除”。后者是资料准入不足，不是学生不满足资格，也不是学校没有规定。
- [ ] 可复用不超过6道T029核查题作为已见诊断题，在human-review中标记；其他从原文重新拟题。不要把该集宣称为随机学生问题、独立盲测或教师标注。

上述覆盖维度可以重叠，不要求把主题、题型、条件轴相加凑总数。若原文不能支持某个预想题，冻结前换为能严谨标注的题，不硬凑事实；没有结果分数作为选题依据。

语料的is_synthetic=false与题目作者是两件事。题集如使用is_synthetic=false，须在authoring_note和报告显著解释：事实依据来自真实文档，**题目与标注由MiMo辅助编制、尚未经用户/导师逐题复核**。不要用一个布尔值暗示人工来源。

## 2. 标注、等价来源与冻结

- [ ] 每题写清目标事实、来源制度/版本、条件和可答/不足理由。每条证据含document_id、原SHA、实际parser_version、block_id、[start,end)、逐字quote；页码/段落定位另列，数字、否定词、例外、主体、时限不得省掉关键限定。
- [ ] 同一fact_id内是OR，每条替代来源必须**独立完整支持同一个事实**；不同必要事实各自一个fact_id。不能把“医院证明”和“书面说明”、宽泛期限和精确期限、不同年级规则合并为等价。复合问句可拆事实，但不能将本应联合支持的两半证据放入OR。
- [ ] 在当前20份原文中，用正文阅读/字面查找检查同事实来源，重点检查教学管理族、考试制度与重叠学业管理DOCX；不凭Top5决定gold。明示版本的题只认该来源约束内证据，其他版本即使同句也不能偷换；未限定版本且有实质冲突的题应消歧或标不足。
- [ ] 不足题不能用“没搜到”作证。记录检查过哪些有关文件/条款，或列明被筛除来源及原因；只断言在冻结首批/条件范围内缺依据，不概括整个学校。
- [ ] 所有quote必须等于解析块切片、通过既有证据校验；可答题的每条gold必须通过该题筛选。程序化核对证明定位与准入，语义等价仍需逐条阅读；写明证据层级。
- [ ] **评测前**保存freeze.json：问题集与标注文件、v1.1 manifest、20份文件、解析/分块/检索相关实现、模型身份的hash/版本；写入本轮拟题来源及人工复核状态。仅哈希当前20份，不反复哈希1182份或整个模型权重目录。

`human-review.md`提供24题核对表：题目、条件、必要事实与版本、证据页码/短引句、等价来源理由或不足原因、待确认点。人工复核栏初始统一为“未复核”，MiMo不得替用户/导师签“通过”。原文可回溯到本地PDF/DOCX及preview锚点，不只给内部hash。

## 3. 三模式各一次，冻结后不调参

- [ ] 使用同一v1.1包、24题、逐题conditions、TopK=5，BM25/Dense/Hybrid各正常跑一次；BGE仅本地加载。沿用分块500字符、BM25 k1=1.5/b=0.75、RRF k=60及现有每路候选数。
- [ ] 保存每模式原始stdout JSON、stderr、真实退出码；结果中的题集/manifest hash必须与freeze一致。记录实际索引块数、向量模型身份、长块截断数；单次耗时不是稳定性能指标。
- [ ] 无需为了复用一次编码改核心框架；使用现有CLI，每模式一次即可。失败先保留产出、定位本地原因，不反复调整题目/参数来获得理想分数。

现有CLI参数已核对。题集标注和冻结完成后，在backend目录运行：

```powershell
Set-Location 'F:\Collage Paper\step2_code\backend'
$evalRoot = 'F:\Collage Paper\data\evaluations\sicau-rag-pilot-eval-v1'
$corpusRoot = 'F:\Collage Paper\data\corpora\sicau-rag-pilot-v1.1'
$modelDir = 'F:\Collage Paper\step2_code\backend\models\bge-small-zh-v1.5'
$resultsDir = Join-Path $evalRoot 'results'
New-Item -ItemType Directory -Path $resultsDir -Force | Out-Null
foreach ($retrievalMode in @('bm25','dense','hybrid')) {
    $modelArgs = @()
    if ($retrievalMode -ne 'bm25') { $modelArgs = @('--model-path', $modelDir) }
    & '.\.venv\Scripts\python.exe' -m campus_assistant.evaluation.run `
      --manifest (Join-Path $corpusRoot 'manifest.json') --corpus-root $corpusRoot `
      --questions (Join-Path $evalRoot 'questions.json') --top-k 5 --mode $retrievalMode `
      @modelArgs > (Join-Path $resultsDir "$retrievalMode.json") `
      2> (Join-Path $resultsDir "$retrievalMode.stderr.log")
    $evalExit = $LASTEXITCODE
    $evalExit | Set-Content -LiteralPath (Join-Path $resultsDir "$retrievalMode.exitcode.txt")
    if ($evalExit -ne 0) { throw "$retrievalMode failed with exit $evalExit; inspect saved output" }
}
```

这是首次运行命令；若已有结果，先另存版本，不能直接覆盖失败或旧冻结产出。如果发现实际标注错误，应保留旧题集/结果、说明语义修正理由并更新数据版本；不是因模型失分就重写问题。

## 4. 结果、失分原因与下一步建议

- [ ] 汇总三模式Recall@5/Hit@5/MRR@5，明确可答分母。Recall沿用“完整覆盖必要事实组”的宏平均；Hit/MRR按当前实现以首次与gold跨度相交的命中计，**不是整题答对率**。不足题单列空检索率，并分开“未记载”与“准入排除”，不叫模型拒答率。
- [ ] 给24题逐题结果及题型/条件分组。与T027分表展示，不合并分母、不宣称跨数据集分数高低证明能力提升；不预设Hybrid优胜。
- [ ] 从真实结果选4—6个案例：至少一个多事实、一个指定版本、一个条件准入、一个有命中但无所问依据。区分可观测现象与原因假设；页级切块、同族重复、错版本、向量截断等只有检查相应记录后才能下结论。
- [ ] 用2道题按已存排名手算指标，建议一题多事实、一题等价来源；与机器值核对。无需扩展新指标平台或测试矩阵。
