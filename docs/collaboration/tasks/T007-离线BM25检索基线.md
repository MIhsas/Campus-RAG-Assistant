## 1. 确定性分词

`tokenize(text: str) -> list[str]`：用正则按原顺序提取 `[\u4e00-\u9fff]+|[A-Za-z0-9]+` 片段。汉字连续段长度 1 时保留单字，长度 >=2 时滑动生成相邻二元组；ASCII 段整体 lowercase。其他字符作分隔符，不跨分隔符合并，不做停用词/同义词/繁简/拼音/Unicode 规范化。查询和正文使用完全相同函数。非 str 抛 ValueError。

必须手工断言：`缓考申请 2024 ABC` → `['缓考','考申','申请','2024','abc']`；`考` → `['考']`；`缓，考` → `['缓','考']`；`ABC2024` → `['abc2024']`；空白标点 emoji → []。因此单字查询不必命中长词，这是已知策略限制，不偷加另一套分词逻辑。

## 2. 索引与分数

`BM25Index(chunks, *, k1=1.5, b=0.75)`；`search(query: str, *, top_k=5)` 返回有序命中列表。k1 为有限实数 >0，b 为有限实数且 0<=b<=1，拒绝 bool、NaN、Inf；top_k 严格整数 1—100，拒绝 bool。参数错误 ValueError，空查询或全无词元返回 []。

每个 chunk 只索引 text，不把 metadata/title/source 加入正文，也不隐含政策过滤。chunk_id 必须非空字符串且唯一，重复应报错，不能悄悄覆盖。仅接受 T006 内部 chunks 契约，至少对 chunk_id/text 类型进行明确校验。存储输入深拷贝，调用者改输入/返回结果不影响索引或其他查询。

设 N 为有至少一个词元的 chunks 数，空词元 chunk 保留在总计数但不参与 N、df、avgdl 和命中。dl 为词元个数（含重复），avgdl 为有效 chunks 平均 dl，df(t) 为包含 t 的有效 chunk 数。N=0 直接返回 []。

本任务固定正 IDF 变体：

```
idf(t) = ln(1 + (N - df(t) + 0.5) / (df(t) + 0.5))
contribution(t,d) = idf(t) * tf(t,d)*(k1+1) /
                    (tf(t,d) + k1*(1-b+b*dl(d)/avgdl))
score(d,q) = sum(contribution(t,d) for t in unique_query_terms if tf(t,d)>0)
```

查询词元去重后按首次出现顺序求和；重复查询词不重复加权，零词频项贡献 0。无匹配不返回零分占位。分数降序，同分按 chunk_id 字符串升序稳定排序，然后截取 top_k。分数返回有限 float，不提前舍入，不作概率/置信度解释。

背景参考：[Stanford《Introduction to Information Retrieval》BM25](https://nlp.stanford.edu/IR-book/html/htmledition/okapi-bm25-a-non-binary-model-1.html)。参考其词频和长度归一化思路；本单分词、正 IDF 与去重规则以上述明确契约为准，不声称与任意第三方库默认输出完全一致。

每条命中返回 rank（从 1）、score、chunk（完整独立拷贝）、preview_url（`/preview#` 后 document_id/block_id 分别 URL 编码，safe=''）。提供 `matched_terms`，每项含 term、tf、df、idf、contribution，顺序沿用去重查询顺序，仅列正匹配项。贡献和应与 score 近似相等，便于解释检索依据；不生成政策答案。

## 3. CLI

`python -m campus_assistant.retrieval.search --manifest <path> --corpus-root <path> --query "缓考申请" [--max-chars 500] [--top-k 5]`

参数验证先于文件读取；max_chars 同 T006，top_k 同 search。k1/b 本轮 CLI 固定默认，不增加选项。调用 chunk_manifest 一次，不重复 parse/validate。stdout 单个 UTF-8 JSON：schema_version=`1.0`、retriever_version=`1.0`、tokenizer_version=`cjk_bigram_ascii_v1`、query、query_tokens（原始含重复）、parameters（max_chars/top_k/k1/b）、valid、document_count、parsed_count、chunk_count、indexed_chunk_count、hits、errors。

成功包括无命中退出 0；有上游错误退出 1、valid=false，保留可用 chunks 的命中与原错误，不伪装整批成功；参数错误退出 2、stdout 空、stderr 明确原因。沿用本地路径限制，不输出异常绝对路径。无模型、下载、持久化索引、任意远程 URL 输入或自动回答。
