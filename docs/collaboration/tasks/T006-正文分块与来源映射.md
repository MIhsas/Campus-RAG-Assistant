## 契约

新增 `src/campus_assistant/corpus/chunk.py`，公开 `chunk_documents(documents, *, max_chars=500)`，输入为 parse_manifest 的 documents，属于内部解析契约，不得修改输入。max_chars 为严格整数 1—10000，拒绝 bool/浮点/字符串/越界，ValueError 中文说明。

返回有序 chunk 字典列表：文档输入顺序、block.ordinal 顺序、片段顺序。无正文块返回空列表。字符索引按 Python 字符串，不是 token 或字节。

- paragraph：连续无重叠窗口，start=0,max_chars,...，end=min(start+max_chars,len(text))；text=原文[start:end]。不 trim、清洗、重复或添加文字；空文本不产出 chunk。
- table_row：整行一个 chunk，完整保留 cells 和 text。超过 max_chars 不拆行，附 `TABLE_ROW_EXCEEDS_MAX_CHARS` 警告，README 解释软上限例外；不补表头、不伪造继承上下文。空 text 但有非空 cells 属于输入契约异常，明确 ValueError，不静默丢内容。
- 未知 kind 明确 ValueError。
- 字段：chunk_id、document_id、block_id、ordinal（文档内从 1 连续）、kind、text、char_start、char_end（半开区间）、locator（原块位置）、cells（表格原列，段落 null）、metadata（原文档独立深拷贝）、parser_version、chunker_version、strategy、max_chars、warnings。
- chunker_version=`1.0`，strategy=`block_window_v1`。metadata 中来源、sha256、版本、日期、scope、is_synthetic 原样保留；null 不改为默认日期/全校适用。locator 不伪造更精确行号/页码，细粒度位置由 char_start/end 表达。
- chunk_id：对 `[document_id,metadata.sha256,parser_version,block_id,chunker_version,strategy,max_chars,char_start,char_end,text]` 以 ensure_ascii=False、separators=(',', ':') 编码 UTF-8 JSON，计算 SHA-256 完整十六进制。不得用时间、随机数或绝对路径。同输入配置稳定，正文/版本/配置变化可区分。
- warnings 独立复制原文档警告并追加本块警告，不能共享可变对象而互相污染。

原文映射使用 `/preview#<URL编码document_id>/<URL编码block_id>`，字符区间供后续细粒度引用。本单只在 README 展示，不改预览页。

## CLI

支持 `python -m campus_assistant.corpus.chunk --manifest <path> --corpus-root <path> [--max-chars 500]`。调用已有 parse_manifest 一次，不再重复 validate。

stdout 单个 UTF-8 JSON 对象，字段 schema_version、chunker_version、strategy、max_chars、valid、document_count（沿用解析器）、parsed_count、chunk_count、chunks、errors。schema_version=`1.0`。解析错误原样保留；部分成功保留成功文档 chunks、valid=false、退出 1；全部成功退出 0；命令参数错误退出 2，不输出伪造成功 JSON。沿用已有路径限制及安全中文错误，不泄漏绝对路径或凭证。不添加 --output 覆盖选项，需要保存时重定向到明确新测试文件。
