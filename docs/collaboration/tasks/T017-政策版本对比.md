# T017 政策版本对比

日期：2026-09-27；task_revision=v1。Astra 发布，MiMo v2.6 Pro 执行；前置 T016-R2 通过。

## 交付目标

完成“选择同一政策的两个版本→查看新增/删除/修改/未变条款→查看两侧原文与适用范围→复制差异摘要”的页面闭环。沿用 FastAPI、静态页面和原文预览，不使用模型总结、不引入新框架或数据库。

本轮对比是文字差异，不判断哪个版本适用于某个学生，不把日期较新直接称为现行有效。必须展示两侧版本、发布日期、生效/失效日期及适用范围；版本标签和元数据分别显示，缺失项写未标注。

## 实施范围与步骤

路径相对于 step2_code/backend。允许相关代码、夹具、聚焦测试/脚本、README 和 submissions/T017；不改旧 gold、parse-corpus 或 Astra 文档。

1. 新增独立 `examples/comparison-corpus/`，至少两个同 policy_group_id 的合成 TXT 版本，含一个修改条款、一个新增、一个删除、一个未变条款，以及第三个不同政策组文档用于选择约束验证。示例可修改缓考申请期限，但明确标为虚构测试。旧语料与评测基线不动。新增独立演示入口，显式注入比较语料，默认产品启动不注入合成数据。
2. 新增 `comparison/service.py`、`api/comparison.py`：从实际解析文档分组列出版本，GET `/api/v1/comparison/groups`；POST `/api/v1/comparison` 输入 left_document_id/right_document_id。拒绝同文档或不同政策组比较。返回两侧元数据、四类计数、块级差异条目及原文链接/ID/哈希/精确跨度。
3. 使用确定性文本比较。优先以“第X条”标识对齐同条款，再对未编号正文按保持顺序的文本匹配处理；同条款内容改变标修改，未匹配条款为新增/删除。不得仅按列表下标配对导致新增一条后后文全部假修改。修改条款可标记句内差异，但整段原文必须逐字保留。说明该算法的条款重编号/移动/重复标题限制，不额外开发复杂语义对齐。
4. 新增 `static/compare.html`：政策组选择、左右版本选择、交换左右、对比按钮、差异总览、默认只看变化/显示全部开关、左右对应条款。新增/删除/修改不能仅靠颜色区分，保留明确标签；两侧原文分别跳转预览。长条款可展开，不截断后冒充完整原文。结果绑定提交时版本快照；请求失败不展示上次结果为新比较成功。
5. 支持复制纯文本差异摘要，包含左右版本身份、差异类型和条款原文、来源；无需导出 Word/PDF。现有各页增加“版本对比”导航入口，不重构旧页面。不把页面复制行为当作模型生成结论。
6. 比较结果仅显示服务器当前已加载语料；README 写明语料更新需重启演示/重新加载，不宣称磁盘实时监控。旧版本不等于失效版本，演示文字如实表述。
