# T031 对照实验报告（experiment-report.md）

> **口径（按任务书）**：本实验是「**增加用户文件选择条件后的辅助检索对照**」——用户显式选择一份文件作为**额外输入条件**，候选范围被人为收窄。**不是**无额外输入的检索算法提升，**不是**系统自动理解版本的能力证明，**不是**全校准确率。未选择该条件时（旧行为）同主题多版本混排仍可能发生，属**已知限制**。gold 仅用于评分，原题/原 gold（T030 v1.3）未改。

## 1. 设置

| 项 | 值 |
|---|---|
| 题目 | T030 v1.3 定题 10 道：q03/q04/q11/q12/q14/q15/q16/q17/q18/q19（题面均明确文号/文件名） |
| 选择映射 | `data/evaluations/sicau-rag-source-selection-v1/selection-map.json`（**跑前冻结**，SHA-256 `42d63bc4558584c0…`）：题面文号/文件名 + manifest 目录**人工唯一匹配**（10/10 无歧义，不从 gold 文档 ID 或检索排名反推） |
| 对照分支 | baseline=无 document_id（旧行为）；selection=document_id（映射所选文件） |
| 固定项 | 同题面、同原四条件（10 题条件均为空）、同 TopK=5、同三模式（BM25/Dense/Hybrid，本地 BGE） |
| 索引 | 每次运行建库一次、文档最多编码一次，全部查询复用（无重复建库、无调参） |
| 冻结 | `data/evaluations/sicau-rag-source-selection-v1/freeze.json`（选择映射+当前实现哈希+模型身份；**T030 冻结未改**） |
| 逐题输出 | `data/evaluations/sicau-rag-source-selection-v1/experiment.json`（逐题 R/H/M、命中文档分布、每题选中 ID、命中序列） |

## 2. 未选分支与旧行为一致性

baseline 的命中序列（document/block/span）与 T030 存储排名逐项对比：**30/30 一致**（10 题×3 模式）。未选分支确实代表旧行为。

## 3. 汇总（K=5，n=10；由本次逐题数据重算）

| 模式 | 分支 | Recall | Hit | MRR |
|---|---|---|---|---|
| BM25 | baseline（无选择） | 0.550 | 0.600 | 0.350 |
| BM25 | **selection（用户选文件）** | **0.900** | **0.900** | **0.503** |
| Dense | baseline | 0.500 | 0.500 | 0.233 |
| Dense | **selection** | **0.900** | **0.900** | **0.548** |
| Hybrid | baseline | 0.400 | 0.400 | 0.283 |
| Hybrid | **selection** | **0.900** | **0.900** | **0.500** |

解读：差异来自**用户提供的额外条件**（范围收窄）与该条件消除了同主题他版文件的排名挤占；不得读作检索算法变强。baseline 数值低于 T030 全 24 题基线是因此处 10 题为指定版本困难组（与 T030 分组观察一致）。

## 5. 不改善与失败（如实记录，无预设提升目标）

- **q19 全模式不改善（0→0）**：选中文件正确（ddf41747，命中均在该文件内），但 gold 证据块（484acc3a，PDF 第6页第九条「取消该科目的考试成绩」）在该文件内仍未进 top5——同文件内作弊条款块（第六/七/八条）排名更前。说明**文件选择解决跨文件混排，不解决文件内部排序**；这是检索侧问题，本任务不调优。
- q03 bm25/q12 dense 等 selection 分支 MRR 较低（首相关排在文件内第 5 位），Recall/Hit 达标但排序仍弱——原样记录。

## 6. 已知限制与后续

1. 本条件由用户提供：不选择时（默认）行为与旧版一致，混排问题依旧存在。
2. 单文件单选；不支持多选/自动猜 ID/查询内年份推断版本。
3. 文件选择与四项适用条件求交；所选文件被条件排除时返回无准入（不放宽）。
4. n=10 单次运行、无显著性检验；模型辅助实验记录（人工复核状态：实验映射由题面+目录规则生成并已冻结，未经人工签署）。
