```powershell
Set-Location 'F:\Collage Paper\step2_code\backend'

# 1) 启动本地演示服务（模拟生成器，零外部请求；Ctrl+C 停止）
```

2. 打开 http://127.0.0.1:8010/ask ，依次核验：

| 步骤 | 操作 | 预期 |
|---|---|---|
| a 模式表达 | 查看按钮区提示 | 「整理依据」=只整理摘录不调模型；「生成答案」=生成+引用；状态条显示可用操作 |
| b 纯摘录 | 输入“缓考申请需要什么材料”、年级 2023 → 整理依据 | 标签“原文摘录 / 未生成答案”；快照含问题/模式/方式/条件/证据数 |
| c 模拟生成 | 同一问题点“生成答案” | 等待态“生成中…”；结果带“【模拟输出，非真实 DeepSeek 回答】”段落与 E 编号 |
| d 引用定位 | 点段落中的 E1 | 页面滚动并**高亮**对应证据卡 |
| e 原文 | 证据卡“查看原文” | 打开 /preview#… 定位原文；卡片含标题/适用范围/日期（标注非资格认证） |
| f 复制 | 点“复制问题与摘录” | 剪贴板为纯文本：问题、条件、段落（依据 E1）、【E1】来源与原文 |
| g 材料不足 | 提问“模拟不足怎么办”→ 生成答案 | 标签“材料不足 / 未生成答案”+ 原因（模拟标记） |
| h 失败转摘录 | 提问“模拟失败测试”→ 生成答案 | 标签“生成失败 / 未返回答案”+“查看本次问题的原文依据”；点击后以**原问题/条件**返回摘录（不调模型）；改控件不影响快照 |
| i 本机历史 | 勾选“在本机保存历史”→ 重复 b/c | 历史列表出现条目（保存时间/状态标签/条件） |
| j 历史恢复 | 点条目“查看” | 本地渲染 + 横幅“历史结果，资料可能已更新”；**Network 无新请求** |
| k 删除/清空 | “删除”单条、“清空历史”；取消勾选 | 删除生效；清空后提示“未开启保存”；取消勾选提示“已停止保存新结果；已保存的 N 条记录仍保留…” |
| l 无证据短路 | 提问“宿舍门禁时间是几点？”→ 生成答案 | “材料不足”，本地短路（模拟服务器日志无 mock 调用记录差异可自查） |
