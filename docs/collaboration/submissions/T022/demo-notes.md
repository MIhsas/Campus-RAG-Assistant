## Astra 浏览器主路径检查表

| # | 操作 | 预期 |
|---|---|---|
| a 正常首页 | `serve-corpus.py --manifest … --corpus-root …`（最小配置）→ `/` | 中性“校园助手”；能力状态实时读取：语料成功/错误数与资料性质、检索模式=关键词、生成器未配置、ASR 未配置、模板/规则未配置（附“不代表学校事项无模板/规则”说明）、版本对比可否 |
| b 状态真实性 | 启动后不点任何生成按钮 | Network 无任何生成请求（仅状态/列表 GET） |
| c 搜索/摘录 | /search 或 /ask 整理依据 | BM25/摘录正常；“生成答案”按钮禁用并提示未配置 |
| d 未配置提示 | 点击各未配置入口 | 明确不可用说明，不诱导“真实政策事项已有完整模板” |
| e 显式配置后 | 加 `--procedures`/`--self-check` 重启 | 首页对应状态变为“已配置”；功能可用 |
| f 演示首页 | `demo-campus.py` → `/` | 演示问题保留（仅演示入口） |

生成器启用验证（可选，零外部）：`--generator deepseek` 未配密钥时首页/启动报告明确“已降级”，摘录仍可用；配置后“生成答案”仍需用户点击（启动/状态/摘录零调用已在测试与 config-combos C5 验证）。
