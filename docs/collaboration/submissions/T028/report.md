## 修复摘要（对照返工单）

### 1. 答辩操作与实际一致（defense-script v2，逐项 API 实测）

- **宿舍晚归原题**：实测 `status=evidence_only`、5 条缓考/学籍类摘录——保留该题改述为“**有命中但不回答该问题**”（命中≠答案），不再预言空/不足。
- **不足演示**：改用「缓考申请模拟不足」+生成答案 → 实测 `insufficient_evidence` +「【模拟输出】材料不足（mock）」（**明确 mock 分支**，不作真实拒答能力证明）。
- **失败演示**：「缓考申请模拟失败」+生成答案 → 实测 **HTTP 502 GENERATOR_ERROR** +“可改用原文摘录重试”——展示显式报错与**用户显式**转摘录（非自动兜底）。
- **界面区分**：检索演示固定**问答页 /ask**（E 编号证据包）；搜索页=检索结果列表，不再混写。首页段改按 **demo 首页实际行为**（演示问题 + search/status、ask/status 两个读数），六接口能力面板列为〔备选 A：正常入口〕。
- **办事降级**：删除“清空条件/若可复现”，给出确定案例——**成绩复核 + 年级 2023**（实测 `insufficient`/`saveable=false`/2 issues/步骤降级），对照缓考 2023 `ready`。
- **时长**：主线 9 段合计 ≈9 分 50 秒（<10 分钟），其余移〔备选〕B1—B4。

### 2. 引用口径：结构校验 ≠ 语义正确性（system-design/thesis/defense 同步收紧）

- 实测确认 `validate_generation` 为**结构校验**（不受支持文本+合法 E1 → kind=answer）。
- 表述统一：原文摘录/模板引用=跨度、哈希、准入的**结构可核对**；生成段落引用**编号**受约束但**编号有效≠忠于证据**；零证据可本地短路，**非空不相关证据不保证识别不足**；生成器可返回不足状态但可靠性未验证——**无可靠拒答保证**。删除“所有结论都能回到原文”“材料不足不生成/不编造”“证据核查兜底”等绝对表述；不新增语义校验器。

### 3. 数据边界与架构图（system-design/thesis/runbook/README）

- 删除“所有数据本地/数据不出机”绝对口径，改为：**默认离线全程不出机；开启 DeepSeek 并用户点击后**——生成出站=问题+选定证据摘录+适用条件；规划出站=用户快照+工具/事项声明+有界观察（以实际 messages 构造核对，verification §1）。
- 架构图补 **EXT 外部模型服务节点**与两条出站边（标注数据范围）；存储表新增“出站数据”行；明确“本地存储≠处理全程不出机”。

### 4. 随单校正

- **源码路径**：`asr/{audio,adapter}.py` + 路由 `api/asr.py`（`asr/api.py` 不存在）；evidence-matrix 的 `tests/…`/“同上”占位全部换成可定位真实文件；路径审计修正为**范围限定表述**（字面路径 17 条 0 缺失；括号写法的展开范围如实声明，ASR 行已补正）。
- **比较算法**：改述为 `difflib.SequenceMatcher` 顺序匹配 + 相似度分级（内部函数名 `_lcs_pairs` 不代表严格 LCS；不改实现）。
- **演示时长**：主线 ≈9 分 50 秒 + 备选段（见第 1 点）。
- **冻结数据复现**：runbook 分列“评测复现（直接读冻结数据）”与“开发用途 assemble（会重写语料/manifest，勿例行执行）”。
