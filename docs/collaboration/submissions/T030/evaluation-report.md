## 4. 失分案例（按事实缺口，不从 top5 反推 gold）

1. **指定版本族整体偏低（q03/q14/q15/q17/q19）**：这些题的 gold 均限定单一版本/来源文，检索 top5 常被同主题他版条文占满（例：q14/q15 的「申请条件课程要求」与2020/2026/2025 版转专业条款混排；q19 的「违纪处理」被作弊条款挤出）。gold 版本消歧是 R1 明确要求（不同版本不合并），此类失分是**版本约束下的真实检索难度**，不回改为泛问换分。
2. **q03（bm25/hybrid 0）与 q14/q15/q19（三模式 0）**：top5 内无 gold 所在块。q03 的 bed3ac/69af5976 被同文他块与他文短块（347b2fb1 等零散小块）抢占排名；q14/q15 gold 在 d1fe/9d80c82d、5cb2/44392bef 的条款列表块内，命中分散在同文其他块。
3. **q11（bm25 recall 0.5）**：四必要事实中 f1/f2（68fb/8a790c05）被 top1 整块覆盖，但 f3/f4 所在 43602ebd 未进 top5——BM25 排名被教学管理族同主题块（0476dada/4bc986e4/76e08b7b/9de19468）占据。**多事实 AND 的部分命中按组计分，不满分**。
4. **q07（dense 0）与 q12/q17（dense/hybrid 0）**：dense 在口语改写（q07「没通过」）与清单型条款（q12 三项条件、q17 30% 上限）上召回的块与 gold 块错位；BM25 反而命中（q07/q12/q17 的 bm25 非零）——词面重叠对短条文更有效。

## 5. 观察与假设（严格区分）

**观察**（可由本次数据直接复核）：

- O1：q05 替代源补全使 dense MRR 0.2→0.5、hybrid 1/3→1（同一 rev1 排名、只换 gold；见 §6 手算与 fix-checks 回归输出）。R1 指出的「旧 MRR 不能用来判断算法弱点」得到实证。
- O2：q10 跨版本源补全后三模式由部分/零分升至满分（bm25 0→1、dense 0→1、hybrid 0.25→1，同一 rev1 排名）。
- O3：72 条排名与来源逐项一致；gold 未变的 18 题分数零漂移——合并/复用路径本身未引入数值误差。
- O4：指定版本组 Recall（0.43–0.57）显著低于 direct/多事实组；零分题全部有同主题他版/他块条文占位。

**假设**（未经本次实验证明，仅列为后续可验证方向）：

- H1：版本号/文号在 query 中的词面（「校教发〔2023〕1号」）对 BM25 贡献有限，因为多版本条文正文几乎不含版本号——若成立，版本消歧题需要结构化版本过滤而不是词面匹配。
- H2：q07 的口语改写（「没通过」）与 dense 分词/向量不匹配是其 dense 0 分主因。
- H3：短条文（单句条款）在 chunk≤500 的整块向量化中被长块稀释，导致 dense 在清单题上弱于 BM25。
