# 答辩演示脚本（defense-script.md）｜8—10 分钟

> T028 交付包｜基于 `demo-campus.py` 统一离线演示（合成语料 + **明确标注的模拟生成器** + 模拟规划器）。
> **证据层级声明（开场先说）**：本演示全部为本地合成/模拟数据；生成与规划按钮的输出是**模拟**（页面与输出内含“【模拟】”标注）；T014 真实问答与 T025 真实规划为**历史受控冒烟记录**（讲解时明确 partial）；本轮未新做浏览器实操（脚本为预期操作单，实操证据归属各历史任务验收）。
> 时长分配：开场 45s｜功能演示 6—7min｜实验 1.5min｜收尾/边界 30s。

- 说明边界（照读证据层级声明）。
- 启动演示（提前启动好，端口 8030）：

```powershell
Set-Location 'F:\Collage Paper\step2_code\backend'
& .\.venv\Scripts\python.exe scripts\demo-campus.py --port 8030
```

## 1. 首页：能力状态（60—75 秒）

**操作**：打开 `http://127.0.0.1:8030/`。
**预期可见**：演示首页（含合成演示问题）；能力状态实时读取——语料 2+ 文档、合成资料标注、检索模式、生成器/ASR/模板/规则配置状态、“已配置≠已验证”说明。
**讲解要点**：
- 状态是**接口实时读取**，不是写死文案；“已配置”只代表本地开关，不代表服务已验证。
- 指向首页演示问题可点击（带入问答页）。
**证据层级**：[实现+模拟演示]；首页状态聚合 T022 验收（历史浏览器证据）。

## 2. 检索与摘录：可核对的原文依据（90—120 秒）

**操作**：进入“证据搜索”或问答页；问题输入「缓考申请须由谁批准」；条件选 年级=2023；模式 关键词；点「整理依据」。
**预期可见**：原文摘录卡片（E1…），含原文文本、文档/块定位、“查看原文”链接（preview 页逐块原文+页码/行号定位）；顶部条件快照显示“年级=2023”。
**讲解要点**：
- 摘录不是答案——是**证据**；引用带文档/块/跨度/哈希，可逐字回溯。
- 条件（T011 筛选）在准入层生效，先筛除再排序；空=未知≠适用所有人。
- 点击“查看原文”到 preview 页核对——演示“可核对”闭环。
**证据层级**：[实现+合成语料]；span 对照测试 T021-R1。

## 3. 失败与不足的呈现（60—90 秒）——**必讲，体现诚实性**

**操作**：问答页输入「学生宿舍晚归如何处理」→「整理依据」。
**预期可见**：明确空/不足提示（合成语料无该主题），不编造内容。
**再操作**（可选，30s）：办事页选择事项后清空条件再生成——或展示“依据不足，暂不可保存”样例（若演示模板下可复现）。
**讲解要点**：
- 系统对“没有依据”与“失败”都有显式状态；不足信息输出为“资料未说明，请向办理部门核实”。
- 呼应评测发现：**有命中≠有依据**（实验部分再展开）。
**证据层级**：[实现]。

## 4. 办事草稿 + 手动保存（90—120 秒）

**操作**：进入“办事与待办”→ 选「缓考申请」→ 条件 年级=2023 → 生成草稿。
**预期可见**：分步办理草稿，每步挂原文引用（可展开核对）；底部“保存”为**手动**按钮；未明确事项列“资料未说明…”。
**讲解要点**：
- 逐引用核对四道检查（来源存在/哈希/跨度/适用条件），不过则降级或不给保存。
- **保存是手动的**——不自动写本机记录；草稿≠学校受理结果。
**证据层级**：[实现+模拟模板]；T016 浏览器证据（历史）。

## 5. 受限流程/模拟规划（90—120 秒）——标注必须清楚

**操作**：进入「受限任务流程」页 → 选事项+问题+条件 → 点「运行固定流程（…非大模型 Agent）」。
**预期可见**：三步骤真实状态（选事项→查找依据→整理草稿）、工具调用次数、结果快照与“进入办理页核对并手动保存”链接。
**再操作**（demo 模式可用）：点「运行模拟规划（演示）」。
**预期可见**：**结果区标注“模拟规划，非DeepSeek实时规划”**；事件只有工具名/状态/次数，无模型思考。
**讲解要点**：
- 固定流程**不是** LLM Agent（标签即如此）；模拟规划是脚本动作，仅演示调用循环。
- 规划器越权会被拒：条件/事项由服务端快照固定，模型传 filters/procedure_id 会“业务前拒绝”。
- 服务端判定完成与否（缺草稿≠完成）。
**证据层级**：[实现+模拟]；真实规划见第 7 节历史记录。

## 常见答辩问题与回答要点

**Q1：为什么不是直接问大模型？**
A：教务结论需要可核对到原文跨度。系统把“引用核对+不足显式”做在服务端；生成是可选增强且每段挂证据编号，材料不足不生成。

**Q2：Hybrid 没有更好，为什么保留？**
A：合成小样本上 Hybrid 与 BM25 recall/hit 持平、MRR 略低——如实报告、不调参凑优势。保留它是为了协议完整性与真实语料复测（词法/语义分布变化可能改变结论）。

**Q3：准确率只有 0.95，能用吗？**
A：0.95 是**合成评测**的证据召回（跨度完整覆盖口径），不是真实校园准确率。真实结论待真实语料+独立人工标注；当前数字用于方法验证。

**Q4：规划/Agent 是真的吗？**
A：分三层说：固定流程是确定性管道（非 LLM）；模拟规划是脚本演示；DeepSeek 规划适配器完成了真实往返冒烟但整体 partial，规划联调“未验证”。三者在界面上标签区分。

**Q5：数据从哪来？合规吗？**
A：当前全部合成资料（明显标注）；系统不爬站、不采集个人数据、密钥仅本地环境变量。真实资料由用户提供来源与适用信息后登记接入。

**Q6：和 RAGFlow / TinyAgent 的关系？**
A：RAGFlow 是调研参考（未集成运行时）；TinyAgent 是接口思路参考，受限编排层为自研（未引其代码/依赖；其示例依赖本地 InternLM+CUDA 与本项目无关）。

**Q7：语音输入效果如何？**
A：本地 FunASR 适配可离线工作（演示入口可选开启），有静音/空转写拦截；识别质量未做评测——不给指标。

**Q8：多用户/部署？**
A：当前定位是单机本地工具（无账户/数据库）；部署化是展望，不在已验证范围。

**Q9：标注是谁做的？客观吗？**
A：执行模型辅助编写、按原文跨度精确定位并冻结哈希、独立于检索结果；两次修订全程留痕（gold-revisions）。不是教师盲评——论文中如实声明；真实 gold 将由人工标注。

**Q10：为什么保存要手动？**
A：防止自动写入用户本机数据；草稿必须人工核对后决定保存——与“学校受理结果”区分。
