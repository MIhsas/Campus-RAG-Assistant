# 公开网站文件采集器实现计划

> 面向 AI 代理的工作者：正式开发使用 executing-plans 逐任务实现。本次先独立执行川农大教务网资料采集，不启动 T029，不修改产品代码、索引或评测 gold。

**目标：** 输入公开网站地址，遍历可达页面并保存可下载附件、网页原文、来源关系和可复核的覆盖报告。

**架构：** URL 发现队列、HTTP 下载器、内容识别与存储、状态数据库、清单报告五个部分。通用核心处理静态链接，站点适配器处理有证据的分页、编码和脚本链接；动态浏览器作为按需补充，不执行登录、提交业务表单或推测附件编号。

**技术栈：** Python 3.12、BeautifulSoup、SQLite、HTTP 客户端；Windows 首次采集用系统 curl 保持正常 TLS 校验，避开本机 Python requests 的 TLS EOF 问题。正式依赖锁定在独立工具目录。

## 本次授权及交付

- 采集起点：https://jiaowu.sicau.edu.cn/ 。首页实际跳转到 `/web/web/web/index.asp`，相对链接必须以最终地址解析。
- 下载范围：教务网公开链接可达的 PDF、Office 文档、压缩包、文本，以及被明确链接为资料的图片；保存公开 HTML 页面作为补充。网页装饰图、脚本和样式不作为资料附件。
- 页面遍历边界为 `jiaowu.sicau.edu.cn`；教务网页面直接链接、位于其他 `*.sicau.edu.cn` 域名的附件也下载，例如存放于 `jwnews.sicau.edu.cn` 的制度 PDF。其他页面链接记清单，不递归扩展全校。正式工具显式配置独立的页面/附件域名白名单。
- robots.txt 404 表示没有该文件；401/403、验证码、登录要求不绕过。站点不可达、robots 5xx 时记录并停止对应站点。
- 不承诺“整个服务器全部文件”。报告以可达队列是否耗尽、失败数、未处理数和适配限制描述覆盖度。

## 正式工具文件结构

目录 `tools/public_crawler/`：

| 文件 | 职责 |
|---|---|
| `cli.py` | 解析 `--url --output --resume --page-host --file-host --delay --workers --max-bytes` |
| `urls.py` | 相对链接解析、fragment 去除、查询参数保留、域名与重定向边界 |
| `fetch.py` | TLS、超时、限速、重试、流式大小限制、robots 和服务器退避 |
| `discover.py` | href、iframe、embed/object、明确脚本 URL、站点地图与分页发现 |
| `classify.py` | HTML/附件区分、魔数校验、文件名与扩展名识别 |
| `store.py` | SQLite 持久队列、SHA-256 去重、原子写入、来源多对多关系 |
| `report.py` | JSONL/CSV 清单、失败记录、HTML 索引、覆盖报告 |
| `adapters/sicau.py` | GB18030 解码、ASP 列表和教务网站点专属规则 |
| `tests/` | 本地 HTTP 集成夹具及 URL、识别、恢复测试 |

## 任务 3：可靠下载

- [ ] 建立本地 HTTP 夹具：302 站外跳转、404、200 HTML 伪 PDF、429 Retry-After、超限文件、半途断开。
- [ ] 单主机初始 2 个并发、请求启动间隔至少 0.5 秒；超时 30 秒，临时故障最多重试 2 次并退避；持续 429/503 自动暂停。
- [ ] 响应流写 `.part`，不超过配置大小；完成校验后原子替换。默认单文件上限 200 MiB，超限明确记录，允许用户调整后续跑。
- [ ] 文件扩展名、Content-Type、Content-Disposition 与魔数联合识别；Office OOXML 验证 ZIP 结构；失败 HTML 绝不记为下载成功。
- [ ] Windows 文件名移除控制字符和保留字符、处理保留设备名、限制长度；中文显示名与原始 URL 独立存储。
- [ ] 运行夹具测试，验证重试次数、退避和错误分类；不通过真实网站施加异常负载来测试。

## 任务 4：持久状态与来源

- [ ] SQLite 表：`urls(url PRIMARY KEY,status,attempts,error)`、`edges(source_url,target_url,label)`、`objects(sha256 PRIMARY KEY,path,bytes,mime)`、`captures(url,sha256,fetched_at,status_code,final_url)`。
- [ ] 状态流：queued → fetching → saved / blocked / failed / skipped；重启将遗留 fetching 回到 queued。
- [ ] 每个文件计算 SHA-256，物理文件按 hash 去重，但保存每一个来源页面和下载地址；内容变更保留新版本。

## 本次实站调查对实现的补充要求

| 观察 | 正式实现要求 |
|---|---|
| 首页 302 到深层 ASP 路径 | 链接解析以最后一跳 URL 为准 |
| 网页声明 GB2312，下载响应头里的文件名也使用旧编码 | 网页按 GB18030 解码，Content-Disposition 的原始字节单独解码，不让终端显示编码污染下载路径 |
| `gwmore.asp` 首页只有最近 50 条；公开类别搜索会返回更多 | 搜索表单适配属于覆盖验收必要项；不要只扫首页就报告全站完成 |
| 实测 52 次类别/年份只读搜索发现 1,814 个不同通知 URL | 搜索种子只证明链接被发现；逐条验证正文访问状态 |
| 多个通知返回 HTTP 200，却用脚本提示“该项信息查询未授权，请登录教务系统后查看” | 增加 `login_required_http_200` 内容级状态，保存证据但不计为有效正文；不可尝试绕过 |
| `/jiaoshi/bangong/gongwen/fujian_down.asp?pid=...` 能匿名返回真实附件 | 不按 `jiaoshi` 路径前缀一刀切；依据实际链接和响应权限分类；从响应头获得真实扩展名 |
| 规章制度栏目多份核心 PDF 托管在 `jwnews.sicau.edu.cn` | 页面遍历范围与附件下载范围分开；获取直接链接的校内附件并保留教务网页面为来源，不扩展新闻站页面爬取 |
| 教室课表链接会展开大量教室与周次组合 | 默认排除实时业务查询；本项目收集文档，不穷举业务查询参数 |
| 一些旧版“表格下载”链接返回 404，但首页新的表格入口可下载 | 保留失败原网址和成功新版原网址，不能凭名称相似就认定内容相同 |

补充测试验收：同样 HTTP 200 的正常通知和登录提示页必须得到不同状态；响应头中文文件名还原且不能路径穿越；公开附件接口不能被登录路径规则误挡；停止后恢复保留进行中 URL。必须用这些真实场景约束正式工具，不能只测正常 PDF 链接。
